# ♻ EcoNudge – AI-Based Waste Management System

EcoNudge is an AI-powered web application that classifies waste into categories like **Organic, Paper, and Plastic** using a deep learning model and promotes sustainable habits through a reward-based system.

---

## 🚀 Features

- 🧠 AI Waste Classification (TensorFlow + MobileNetV2)
- ⚡ Real-time Prediction with Confidence Score
- 🎯 Reward System for eco-friendly actions
- 🖥 User-friendly Dashboard (HTML, CSS, JS)
- 🌱 Encourages sustainable waste management

---

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Flask (Python)
- **Machine Learning:** TensorFlow, Keras (MobileNetV2)
- **Image Processing:** PIL, NumPy
- **Other Tools:** Git, GitHub
